# CCS Project Overview

## Product

Code Consulting Studio (CCS) is a bilingual EN/PL business website and content platform built with Next.js.

Main domain:

`https://codeconsultingstudio.com`

## Current stack

- Next.js 16.x App Router
- React 19
- TypeScript
- Supabase / PostgreSQL / Auth / RLS / Storage
- Resend
- Google Search Console integration
- Bing market/search integration
- Anthropic for text generation
- PM2 + Nginx on Ubuntu VPS
- Vitest
- ESLint

## Strategic content pipeline

market data
→ trend analysis
→ business relevance
→ content coverage
→ evidence confidence
→ market opportunity
→ recommendation
→ human-reviewed handoff
→ content brief
→ article
→ original article visual
→ human review
→ publication

The system remains human-controlled.

No recommendation auto-publishes content.
No generated visual is auto-approved.
Every future published article must have its own original, topic-specific visual.
